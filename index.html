Panduan Scripting CodeMotion Studio

Anda dapat menulis kode animasi dalam 2 Mode: JavaScript Canvas API (untuk motion graphics 60fps presisi) atau HTML/CSS murni.

Variabel Bawaan (Mode Native Canvas 2D):
  • ctx — Konteks Canvas 2D (CanvasRenderingContext2D)
  • w, h — Lebar & tinggi resolusi aktif (alias width, height)
  • t — Waktu animasi dalam detik (alias time)
  • progress — Progres animasi dari 0.0 hingga 1.0
  • params — Objek parameter slider & overlay (auroraSpeed, starIntensity, title, subtitle, align)
  • easeOutCubic(x), easeOutElastic(x), roundRect(...) — Helper siap pakai
Mode Custom HTML/CSS:

Jika kode dimulai dengan tag <div> atau <style>, sistem otomatis merendernya melalui SVG ForeignObject ke Canvas. Gunakan variabel CSS --progress (0 s/d 1) di dalam CSS Anda untuk menggerakkan animasi!
